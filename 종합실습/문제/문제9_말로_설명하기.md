# 문제 9 — 말로 설명하기 (코드 없음)

각 질문에 **세 문장 이내**로 답하세요. 수식을 써도 되지만 "왜"가 빠지면 0점입니다.
옆 사람에게 말로 설명해 보고, 막히는 곳이 있으면 그 단원을 다시 보세요.

1. 01 의 선형회귀, 03 의 로지스틱 회귀, 11 의 MLP 분류기, 12 의 다중분류기. 이 넷을 "앞의 것에 무엇을 붙인 것"으로 한 줄씩 이어서 설명하세요.
- 선형회귀: 입력에 가중치와 편향을 적용해 연속적인 값을 예측
- 로지스틱 회귀: 선형회귀에 sigmoid를 붙여 이진분류 확률을 예측
- MLP 분류기: 로지스틱 회귀에 비선형 은닉층을 추가해 복잡한 패턴을 학습
- 다중분류기: MLP의 출력 뉴런을 클래스 수만큼 늘리고 softmax를 적용해 여러 클래스 구분

2. 이 과정에서 `(예측 - 정답)` 꼴의 출력 기울기가 여러 번 나왔습니다 (`2(ŷ-y)`, `p-y`, `P-Y`). 각각 어느 손실과 어느 출력 활성화의 짝에서 나왔나요? 왜 셋이 다 이렇게 단순해지나요?
- MSE, 선형 출력 -> 2(ŷ-y)
- BCE, sigmoid 출력 -> p-y
- 교차 엔트로피, softmax 출력 -> P-Y
- MSE 제곱을 미분하면 오차가 직접 나타남
- 나머지 둘은 손실함수와 활성화 함수의 미분 항이 서로 약분되면서 단순해짐

3. "표준화는 train 의 평균·표준편차로만 한다." 이 규칙이 깨지는 걸 오늘 몇 번이나 봤나요? (문제 1, 2, 4 를 떠올려 보세요) 각각 무엇이 새어 들어갔나요?
- 문제 1: 전체 데이터로 결측치 대체 기준을 계산하면 test 정보가 새어 들어감
- 문제 2: 전체 데이터로 표준화하면 test의 평균과 표준편차가 학습에 반영됨
- 문제 4: 분할 전에 표준화하면 test의 분포 정보가 유입
- 따라서 모든 전처리 기준은 train에서만 구해야 함

4. 표준화를 해야 하는 이유가 01 에서 한 번, 09 에서 또 한 번 나왔습니다. 두 이유는 같은 이유인가요, 다른 이유인가요?
- 01: 특성 간 크기 차이가 경사하강을 비효율적으로 만들기 때문에 표준화
- 09: 입력값이 너무 크면 sigmoid가 포화되어 기울기가 거의 0이 되기 때문에 표준화
- 둘 다 학습 안정성과 관련되나 발생 원리가 다름

5. 과적합을 오늘 두 가지 방법으로 '만들었습니다' (문제 2 [2-5], 문제 4 [4-3]). 각각 무엇을 키우거나 줄여서 생겼나요? 공통점은?
   그리고 문제 8 [8-4] 에서는 큰 망의 train 정확도가 1.000 인데 val 도 0.98 이었습니다. 이것도 과적합인가요?
- 문제 2: 다항식의 차수를 높임
- 문제 4: 트리의 깊이를 늘려 모델이 학습 데이터의 잡음까지 외우도록 함
- 공통점: 모델의 복잡도가 커져 일반화 성능이 떨어질 가능성 있음
- 문제 8의 train 1.000, val 0.98은 차이가 작으므로 이것만 보고 심각한 과적합이라고 판단할 수 없음

6. test 는 "딱 한 번만" 본다고 했습니다. 그럼 손잡이(lr, 깊이, C, 은닉수)는 무엇으로 고르나요? 두 가지 방법을 말하고, 데이터가 적을 때는 어느 쪽이 나은지 말하세요.
- 학습률, 깊이, C, 은닉수 같은 설정은 validation 성능이나 교차검증 평균 성능으로 선택
- 데이터가 적을 때는 여러 분할을 활용하는 교차검증이 더 안정적
- test는 최종 모델의 일반화 성능을 평가할 때만 사용할 것

7. 정확도가 97% 인데 쓸모없는 모델(문제 3)과, 정확도 34% 인 모델(문제 8 의 zero 초기화)은 사실 같은 짓을 하고 있습니다. 무슨 짓인가요?
- 두 모델 모두 입력의 특징을 제대로 학습하지 못하고 가장 많은 클래스만 예측함
- 문제 3: 정상 데이터가 압도적으로 많았음
- 문제 8: zero 초기화로 은닉층이 학습되지 않았음

8. 문제 3 에서 로지스틱 회귀가 못 넘은 벽을 문제 4 의 트리는 넘었고, 문제 2 에서는 `1/회전수` 를 사람이 만들어 넘었습니다. 신경망은 이 벽을 어떤 방식으로 넘나요? (08 의 '활성화 없으면 직선으로 붕괴'와 연결해서)
- 로지스틱 회귀는 직선으로만 구분하지만 트리는 조건으 나눔
- 문제 2: 직접 1/회전수라는 비선형 특성을 만들어 한계 및 문제를 해결함
- 신경망은 비선형 활성화 함수가 있는 은닉층을 통해 복잡한 특징을 직접 학습하며 활성화 함수가 없다면 여러 층을 쌓아도 하나의 선형변환으로 합쳐짐

9. 층을 쌓아야 하는 이유(10 전반부)와, 쌓으면 생기는 문제(10 후반부)를 한 문장씩. 그리고 12 에서 본 처방 두 가지.
- 층을 쌓으면 단순한 특징들을 조합해 복잡한 비선형 관계를 학습할 수 있음
- 하지만 층이 깊어질수록 작은 기울기가 반복해서 곱해져 기울기 소실이 발생할 수 있음
- 이를 완화하기 위해 문제 12에서 ReLU 함수와 He 초기화를 사용

10. 새 설비 데이터를 받았다고 합시다. 정답 열이 없습니다. 오늘 한 일을 순서대로 늘어놓아 "첫날 할 일 목록"을 만드세요 (5~8줄).
- 1. 데이터의 센서 종류, 단위, 자료형과 수집 기간 확인
- 2. 결측치, 중복값, 이상치를 확인하고 데이터의 분포 탐색
- 3. 센서별 평균, 표준편차, 상관관계 분석
- 4. 정답 열이 없으므로 고장 이력이나 정비 기록을 통해 정답을 확보할 수 있는지 확인
- 5. 정답이 없다면 센서 간 관계를 회귀로 분석하거나 이상 징후 탐색
- 6. 정답을 확보하면 train/val/test로 분리하고 train을 기준으로 전처리와 표준화
- 7. 회귀/분류 모델을 학습하고 검증 데이터로 모델을 선택
- 8. test로 최종 성능 평가
