# 실습 1 — 00, 01 복습

수업에서 배운 것으로 **처음 보는 데이터**를 직접 다뤄 봅니다.


## 폴더 안에 있는 것

```
실습1_배포/
├── README.md              지금 보고 있는 파일
├── 실습1_문제.py           문제만 있습니다. 코드는 직접 씁니다
└── 데이터/
    ├── G-02_정비이력.csv        정비 작업 2,112건
    └── T-SP-AGT01_교반특징.csv   교반기 진동 계측 317건
```

## 하는 법

1. 이 폴더를 **통째로** 내려받아 `deeplearning-practice` 안에 넣으세요
2. VS Code 로 `실습1_문제.py` 를 엽니다
3. 터미널 맨 앞에 `(.venv)` 가 보이는지 확인
4. 문제를 읽고 **`# TODO: 여기에 코드를 쓰세요` 아래에 코드를 씁니다**
   (`import` 부터 경로 잡는 것까지 전부 직접 씁니다)
5. 돌려 봅니다

```
cd 실습1_배포
python 실습1_문제.py
```

> **`데이터/` 폴더를 옮기지 마세요.** 코드가 같은 폴더 안에서 찾습니다.

## 문제 구성

| | 내용 | 쓰는 것 | 시간 |
|---|---|---|---|
| **A1~A6** | 정비이력 데이터 살펴보기 | 00 에서 배운 것 | 약 40분 |
| **B1~B2** | 상관계수로 관계 찾기 | 00 에서 배운 것 | 약 15분 |
| **B3~B10** | 손으로 경사하강 돌려 직선 찾기 | 01 에서 배운 것 | 약 45분 |

A 와 B 는 이어지지 않습니다. A 가 막히면 B 로 넘어가도 됩니다.

> 정답 코드는 없습니다. 문제와 "답하기" 질문만 있습니다.
> 코드가 돌아가는 것보다 **답하기에 뭐라고 적었는지**가 더 중요합니다.

## 막힐 때

- **먼저 00, 01 파일을 여세요.** 거의 다 거기 있습니다. 같은 일을 한 줄을 찾아 고쳐 쓰면 됩니다
- `KeyError: '...'` → `encoding="utf-8-sig"` 를 빼먹었습니다
- `ModuleNotFoundError` → `(.venv)` 를 안 켰습니다
- `NameError: name '...' is not defined` → 앞 문제에서 만든 변수를 아직 안 만들었습니다
